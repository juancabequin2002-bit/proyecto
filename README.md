# Ma&LuMakeup

Tienda web hecha en Flask con:

- Página de bienvenida llamativa.
- Catálogo importado desde `MARZO_27.pdf`.
- Panel administrador para editar precios, promociones y stock.
- Pedidos guardados en SQLite.
- Descuento automático de inventario por compra.
- Enlace directo a WhatsApp `3214107108`.

## Ejecutar

```powershell
python app.py
```

Luego abre `http://127.0.0.1:5000`.
